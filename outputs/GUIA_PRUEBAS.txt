=== NETFORGE: GUÍA DE PRUEBAS ===

Topología recomendada:
PC1 Fa0 -> SW1 Fa0/1
SW1 Gi0/1 -> R1 Gi0/1
R1 Gi0/0 -> R-ISP Gi0/0

Orden de configuración:
1. Pegar outputs/SW1-CORE.txt en el switch
2. Pegar outputs/R1-CORE.txt en el router principal
3. Pegar outputs/R-ISP.txt en el router ISP

Pruebas en SW1:
show vlan brief
show interfaces trunk

Pruebas en R1:
show ip interface brief
show ip dhcp binding
show ip route
show ip nat translations
show ip ospf neighbor

Pruebas en PC1:
1. Desktop -> IP Configuration -> DHCP
2. ping 192.168.10.1
3. ping 10.0.0.2
